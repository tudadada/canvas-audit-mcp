# canvas-audit-playwright

> Canvas, WebGL and display-quality assertions for Playwright.

## Features
- **Custom Matchers**: `toBeSharpAtDpr()`, `toHaveStablePacing()`, `toRecoverFromContextLoss()`, `toHaveErgonomicTargets()`.
- **Automated Fixtures**: Seamlessly attach canvas audits to Playwright test pages.
- **Baseline Tracking**: Capture and detect rendering regressions across CI runs.
